# @alikhangholi/iran-sms

> Unified TypeScript SDK for Iranian SMS panels.

**Supported providers:** KavehNegar · SMS.ir · FarazSMS · Ghasedak · MeliPayamak · IPPanel · RayganSMS · ParsGreen · PayamResan

## Install

```bash
npm install @alikhangholi/iran-sms
```
